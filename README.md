# LeetCode Problems

A collection of LeetCode problems that I have solved by myself while practicing Data Structures and Algorithms.

I created this repository as a personal learning and revision space. The idea is to keep all the problems I have worked on in one place so that I can come back to them whenever I need to revise a concept, remember an approach, or prepare for coding interviews.

## What this repository contains

- Problems I have solved on LeetCode
- My own approaches and implementations
- Problems that I may revisit and optimize as I improve

## Why I maintain this repository

I believe revisiting problems I have already solved is an important part of learning DSA. Instead of just solving a problem once and moving on, I want to be able to return to my own solutions and understand how I approached them at that point in my learning journey.

This repository is primarily for my own reference and revision.
